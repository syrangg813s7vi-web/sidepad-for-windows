# Sidepad for Windows v0.2.0

这是一个聚焦双屏激活准确性和 PPTX 阅读体验的功能版本。

## 新增与改进

- Sidepad 现在只在 Windows 主显示器右侧激活；副屏边缘不再唤醒面板。
- 主屏右侧为外侧边缘时，触发区使用完整工作区高度和 12px 宽度。
- 主屏右侧与副屏相邻时，使用居中的 320×12px 触发区，并保留 140ms 防误触延迟。
- 显示器连接、移除、缩放、旋转或主屏设置变化后，触发区和面板会自动迁移到新的主屏。
- PPTX 预览覆盖完整可读区域，按面板实际宽度排版，不再被 640px 最小宽度横向裁切。
- PPTX 使用连续纵向列表展示全部幻灯片，面板宽度变化后自动重新排版。

## 验证结果

- 6 项窗口布局测试通过，包括主屏选择、100%/150% DPI、共享接缝和小高度边界。
- Electron 端到端测试通过，包括边缘展开/收起、网页导航与失败恢复、笔记持久化和 Office 文档预览。
- 使用三页 PPTX 验证连续布局、完整宽度、纵向滚动范围和无横向裁切。
- Windows x64 NSIS 安装版和便携版均完成构建，生产依赖审计为 0 个已知漏洞。

## 已知限制

- 当前 QEMU 来宾无法同时提供两个被 Windows 正常识别的显示输出；“副屏不触发”仍需在真实双显示器或合适的 Hyper-V/VMware 环境补充实机验收。
- PPTX 复杂图表、公式、宏、视频和动画可能无法完全还原。
- 当前版本未配置商业 Authenticode 证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。
