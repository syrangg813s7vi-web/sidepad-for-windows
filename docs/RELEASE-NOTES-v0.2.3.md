# Sidepad for Windows v0.2.3

这是一个修复自动隐藏和关闭生命周期的 Windows x64 维护版本。

## 修复与改进

- 边缘悬停以预览态展开，不主动抢走当前窗口焦点。
- 尚未点击 Sidepad 时，鼠标移出面板会自动收起。
- 点击 Sidepad 后进入交互锁定态，鼠标移出仍保持展开；点击其他窗口失焦后自动隐藏。
- 点击右上角关闭按钮时，主窗口、边缘触发窗口和应用进程会完整退出，不再留下无法唤醒的后台进程。
- README、交互设计和设计—代码对应表已同步更新。

## 验证结果

- 完整 `npm test` 通过，包括 6 项窗口布局测试与 Electron 端到端测试。
- 新增未点击离开收起、点击后离开保持，以及关闭后进程退出的自动化回归测试。
- `npm audit --audit-level=high` 检查通过，已知漏洞为 0。
- Windows 安装版和便携版均以 x64 目标构建，主程序格式为 PE32+ x86-64。

## 已知限制

- 本版本的新增交互已通过 Electron 自动化验证；真实双显示器硬件下“仅主屏激活”仍建议继续补充验收。
- 复杂 PPTX 的图表、公式、宏、视频和动画可能无法完全还原。
- 当前版本未配置商业 Authenticode 证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。
