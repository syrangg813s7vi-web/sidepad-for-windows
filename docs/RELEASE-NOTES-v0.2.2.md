# Sidepad for Windows v0.2.2

这是一个针对新打开网页在窄面板中显示不完整的修复版本。

## 修复与改进

- 响应式网页继续保持 100% 缩放，不改变网站原有布局。
- 对设置桌面最小宽度的网页，优先注入窄栏重排规则，让内容在可读区域内换行，同时保持正常字号。
- 仅当窄栏重排后仍然溢出时才启用缩放兜底，最低缩放为 45%。
- 缩放兜底增加 3% 右侧安全边距，减少页面最右侧被轻微裁切的情况。
- 页面每次导航时重置适配状态，并在加载完成后立即、350ms 和 1200ms 复测，兼容延迟渲染内容。

## 验证结果

- 完整 `npm test` 通过。
- 6 项窗口布局与 DPI 测试通过。
- Electron 端到端测试覆盖网页导航、失败恢复、弹窗链接、笔记、PDF、DOCX、PPTX 和 XLSX。
- 新增 1100px 固定宽网页测试：在 559px WebView 中以 100% 缩放完成窄栏重排，内容不超过可读区域。
- Windows x64 安装版和便携版均由锁定依赖构建，主程序目标架构为 x86-64。

## 已知限制

- 网站可主动阻止样式覆盖；此时 Sidepad 会使用缩放兜底，文字可能相应变小。
- 复杂 PPTX 的图表、公式、宏、视频和动画可能无法完全还原。
- 当前版本未配置商业 Authenticode 证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。
